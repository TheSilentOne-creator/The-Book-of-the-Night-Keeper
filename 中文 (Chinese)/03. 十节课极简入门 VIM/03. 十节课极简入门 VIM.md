## 前言

### 这本教程适合谁？

- 你听说过 Vim 很厉害，但打开后不知道怎么退出
- 你用过 Vim，但只会 `i` 和 `:wq`，觉得它跟记事本没区别
- 你想写代码更快，不想在鼠标和键盘之间来回切换
- 你愿意花几天时间建立“肌肉记忆”，换取未来几年的效率提升

**如果你是上面任何一种人，这本教程就是为你写的。**

### 这本教程不适合谁？

- 你已经精通 Vim，只是想找命令速查卡 → 直接翻附录 B
- 你想把 Vim 变成 IDE，折腾插件比写代码还上心 → 出门右转《精通 Vim》
- 你不想动手，只想“看懂” Vim → 这本教程帮不了你，Vim 是练出来的，不是看出来的

### 学习路线图

```text
第一课（安装）
    ↓
第二课（打开/保存）← 先学会“活着回来”
    ↓
第三课（移动光标）← 手指离开方向键
    ↓
第四课（插入模式）← Vim 的核心秘密
    ↓
第五课（. 命令）← Vim 的精髓
    ↓
第六、七、八、九课（各种编辑命令）← 给 . 命令提供“弹药”
    ↓
第十课（哲学）← 总结 & 下一站
```

> **建议**：每天只学 1-2 课，每课学完立刻练 10 分钟。不要赶进度，要“长”在手上。

## 第一部分：守夜者的十节课（必修）

> **目标**：让你能“得体”地用 VIM 写代码、改配置、活着退出来。  
> **读完这一部分，你已经超越了 80% 的 VIM 初学者。**

### 第一课：VIM 前世今生与安装

- vi 与 vim：功能机 vs 智能手机
- 安装 Vim 并验证环境
- 第一次启动：初识 Vim 界面

### 第二课：打开、关闭、保存文件 —— 活着回来

- 用 Vim 打开文件
- 保存、退出、不保存强制退出
- 守夜者贴士：为什么 `:wq` 比 `ZZ` 更适合新手

### 第三课：用 `h` `j` `k` `l` 移动光标 —— 解放方向键

- 为什么是这四个键？
- 肌肉记忆训练：让手指“记住”主键盘区
- 避坑：初学者最常犯的“手指漂移”

### 第四课：插入模式与模式切换 —— VIM 的核心秘密

- 普通模式 vs 插入模式：Vim 的“双重人格”
- 进入插入模式的多种方式：`i`、`I`、`a`、`A`、`o`、`O`
- 按 `Esc` 回来：这不是 Bug，是 Feature

### 第五课：`.` 命令 —— VIM 里的“懒人键”

- 什么是“上一次修改”？
- `.` 的震撼演示：删一行、再删一行、再删一行
- 点公式：移动 + 执行，再移动 + 再执行
- 互动练习：给多行代码加分号

### 第六课：删除、撤销、恢复 —— 后悔药大全

- 删除字符：`x`
- 删除整行：`dd`
- 删除与 `.` 命令的配合
- 撤销：`u`
- 重做：`Ctrl + r`
- 数字的魔力：`3dd` 删三行

### 第七课：粘贴、复制、修改、替换 —— 搬运文本的艺术

- 复制（yank）：`yy` 复制一行，`y` 配合移动
- 粘贴：`p` 在光标后，`P` 在光标前
- 修改（change）：`c` 删除并进入插入模式
- 替换命令：`r` 替换单个字符
- 替换模式：`R` 覆盖式输入

### 第八课：文件信息、跳转、定位括号和缩进

- 查看文件状态：`Ctrl + g`
- 快速跳转：`gg` 到文件首，`G` 到文件尾，`0` 到行首，`$` 到行尾
- 定位匹配括号：`%`
- 缩进调整：`>>` 和 `<<`

### 第九课：搜索、替换 —— 在文件中“抓人”

- 搜索：`/关键词`
- 下一个匹配：`n`，上一个匹配：`N`
- 替换：`:s/old/new/g`
- 范围替换：`:%s/old/new/g` 替换全文

### 第十课：VIM 的哲学（入门版）

- 普通模式是“休息区”，插入模式是“工作区”
- 操作符 + 动作命令：Vim 是一门语言
- `.` 命令：一次编写，到处执行
- 学习路线图：你已经走完了新手村

## 第二部分：通往专家之路（选修）

> **目标**：让你从“会用”变成“精通”。  
> **这部分内容来自《Vim 实用技巧》的深度解读。**  
> 读完前十课后，根据你的痛点，挑着读：

### 我应该从哪个选修开始？

| 如果你遇到这些情况 | 去读 |
| :--- | :--- |
| 每次都要按好几下才能删掉引号里的内容 | **选修 1：文本对象** |
| 复制粘贴总被覆盖，烦死了 | **选修 2：寄存器** |
| 重复操作太多，手指都麻了 | **选修 3：宏** |
| 不想背命令，想自己“推导”出来 | **选修 4：Vim 是一门语言** |
| 想让 Vim 变成你喜欢的样子 | **选修 5：配置 `.vimrc`** |
| 想让 Vim 变成 IDE | **选修 6：插件生态** |

### 选修 1：文本对象 —— 操作的单位升级了

- 什么是文本对象？（`iw`、`ip`、`i"`、`i(`……）
- 操作符 + 文本对象：`dip` 删除一个段落，`ci"` 删除引号内内容并进入插入模式
- 实战：批量修改 HTML 标签属性

### 选修 2：寄存器 —— VIM 的“多个剪贴板”

- 什么是寄存器？
- 默认寄存器（`""`）、复制专用寄存器（`"0`）、命名寄存器（`"a`-`"z`）
- 实战：同时操作多段文本，互不干扰

### 选修 3：宏 —— 录制操作，一键重放

- 录制宏：`q` + 寄存器名
- 播放宏：`@` + 寄存器名
- 实战：在 100 行代码前面都加上 `//` 注释

### 选修 4：VIM 是一门语言 —— 命令组合的逻辑

- 操作符 + 动作命令：`d` `c` `y` 是动词，`w` `$` `f` 是名词
- 为什么 Vim 不需要背太多命令？（因为学会组合 = 学会新命令）
- 实战：从“按命令”到“想命令”的思维转变

### 选修 5：配置 `.vimrc` —— 让 VIM 变成你的形状

- `.vimrc` 是什么？放哪？
- 基础配置：行号、语法高亮、缩进、主题
- 守夜者推荐配置模板（直接复制可用）

### 选修 6：插件生态 —— 把 VIM 变成 IDE

- 插件管理器：vim-plug（最轻量）
- 必装插件：NERDTree（文件树）、coc.nvim（补全）、fzf（模糊搜索）
- 守夜者提醒：插件不是越多越好，够用就行

### 附录 B：常用命令速查卡

**移动光标**  

| 命令 | 效果 |
| :--- | :--- |
| `h` / `j` / `k` / `l` | 左 / 下 / 上 / 右 |
| `w` / `b` | 下一个词 / 上一个词 |
| `0` / `$` | 行首 / 行尾 |
| `gg` / `G` | 文件首 / 文件尾 |
| `Ctrl + f` / `Ctrl + b` | 下一页 / 上一页 |

**编辑文本**  

| 命令 | 效果 |
| :--- | :--- |
| `i` / `a` | 光标前插入 / 光标后插入 |
| `o` / `O` | 下一行插入 / 上一行插入 |
| `x` | 删除光标下字符 |
| `dd` | 删除整行 |
| `yy` | 复制整行 |
| `p` / `P` | 光标后粘贴 / 光标前粘贴 |
| `u` / `Ctrl + r` | 撤销 / 重做 |
| `.` | 重复上一次修改 |

**文件操作**  

| 命令 | 效果 |
| :--- | :--- |
| `:w` | 保存 |
| `:q` | 退出 |
| `:wq` / `:x` / `ZZ` | 保存并退出 |
| `:q!` / `ZQ` | 不保存强制退出 |
| `:e 文件名` | 打开另一个文件 |

> **守夜者提醒**：不要把这本书当字典查。它是一本需要“练”的书。

### 附录 D：常见坑与解法（新手救急）

| 现象 | 原因 | 解法 |
| :--- | :--- | :--- |
| 按 `i` 没反应，打不出字 | 你不在普通模式 | 按 `Esc` 再试 |
| 按 `h` `j` `k` `l` 变成了输入字母 | 你在插入模式 | 按 `Esc` 退出 |
| `:wq` 报错 `E212: Can't open file for writing` | 没有写权限 | `:w !sudo tee %`（或用 `sudo` 重新打开） |
| 打开文件全是乱码 | 编码问题 | `:e ++enc=utf-8` |
| 按 `Ctrl+s` 卡死了 | 你按了 XOFF 流控制 | `Ctrl+q` 解除 |
| 不小心按了 `Ctrl+z`，Vim 不见了 | 被挂起到后台 | `fg` 回到 Vim |
| 撤销撤多了，想“反撤销” | 不知道 `Ctrl+r` | `Ctrl+r` 重做 |
