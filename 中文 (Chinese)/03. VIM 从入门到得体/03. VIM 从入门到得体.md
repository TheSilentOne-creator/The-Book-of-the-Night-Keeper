## 前言

### 这本教程是给谁看的？

你是不是也觉得，Vim 是那种“人人都说好，但人人都没用明白”的东西？

你身边可能也有这样的朋友：兴致勃勃装上 Vim，练了两天，放弃了。说“太反人类了”。或者在服务器上不小心进了 Vim，死活退不出来，最后只能关掉终端重开。网上搜了一堆“Vim 速成教程”，学完只会 `i` 和 `:wq`，感觉跟记事本没区别。

你可能就是那个朋友。也可能你正在成为那个朋友的路上——然后你翻开了这本教程。

**这本教程不追求“精通”，只追求“得体”。**

什么叫“得体”？

- 打开 Vim 不慌张，知道自己在什么模式
- 能流畅地移动光标、编辑文本、保存退出
- 手指开始习惯主键盘区，不再依赖方向键
- 写代码时不再觉得“Vim 在拖我后腿”

读完这十节课，你就能做到这些。剩下的，是时间和练习的事。

---

### 这本教程不是什么？

**不是《Vim 实用技巧》的替代品。** 那本书是真正的“绝世武功”，但它的符号表示法（`<C-x>`、`>G` 之类的）会劝退零基础读者。这本教程是你的“新手村任务指南”——读完它，你才有资格翻开那本书。

**不是命令大全。** 我只讲 **80% 的场景下会用到的 20% 的命令**。剩下的，等你真的需要了，自己去查 `:help`。

**不是插件配置教程。** 在学会基础操作之前，别碰插件。插件是给懂 Vim 的人用的，不是给新手用的。

---

## 第一部分：守夜者的十节课（必修）

> **目标**：让你能“得体”地用 VIM 写代码、改配置、活着退出来。  
> **读完这一部分，你已经超越了 80% 的 VIM 初学者。**

### 第一课：从“山寨货”到“服务器标配”：VIM 的传奇起点

---

#### 1.1 Vim 是什么？

Vim 是一个在终端里运行的文本编辑器。

和你在《玩转 VS Code》里用过的编辑器不同：

- Vim 没有鼠标
- Vim 没有菜单栏
- Vim 没有可以点的图标
- Vim 只有键盘

听起来很麻烦。但 Vim 有一个特点：**你的手指不用离开键盘**。所有操作都在主键盘区完成。习惯了之后，你写东西的速度会比用鼠标快很多。

你在 01 教程里学会了用 Markdown 写笔记，在 02 教程里学会了用 VS Code 高效写作。现在，你要接触一个和 VS Code 完全不同的编辑器——它没有图形界面，没有插件商店，没有“设置”按钮。但它有一个 VS Code 永远无法替代的能力：**在任何一台服务器上，它都已经在那里等着你了。**

> *Kate 问道：“也就是说，我可以不装任何东西，直接在服务器上用它？”*
> *“没错，它在那儿等你几十年了。”*

---

#### 1.2 一个“山寨货”的逆袭

1976 年，一个叫 Bill Joy 的程序员写了一款编辑器，叫 **Vi**。Vi 很强大，但它不是免费的。

1988 年，一个叫 **Bram Moolenaar** 的荷兰程序员决定：既然用不了 Vi，那我自己写一个“高仿版”。他给项目起名叫 **Vi IMitation**（模仿品），缩写就是 **Vim**。

后来 Vim 的功能超过了 Vi，名字也改了——**Vi IMproved**（改良版）。

**小结**：Vim 从一个“山寨货”逆袭成了行业标杆。别怕从模仿开始，Vim 也是这样走过来的。

---

#### 1.3 为什么用 `hjkl` 移动光标？

Vim 里用 `h` `j` `k` `l` 代替方向键。你可能会问：“为什么不用方向键？”

看下面这张图。这是 Bill Joy 当年用的机器（ADM-3A）的键盘：

![ADM-3A_-_animation](<Images/Chapter 1/1.3/ADM-3A_-_animation.png>)

仔细看 `H`、`J`、`K`、`L` 这四个键——上面印着方向箭头。

当时独立方向键在键盘右边，离主键盘区很远。每移动一次光标，手都要整个挪过去。Bill Joy 干脆直接用这四个字母当方向键，手指不用离开主键盘区。

后来他把这个习惯写进了 Vi 的代码里。Vim 继承了下来，一直传到今天。

**实际手感**：现在，把你的右手食指放在 `J` 键上。摸到了吗？那个键上有个小凸起，是所有键盘用来帮你定位的“锚点”。食指找到这个凸起后，你的手指会自然覆盖在 `H`、`J`、`K`、`L` 四个键上——向右是 `L`，向左是 `H`，向下是 `J`，向上是 `K`。这就是 Vim 的核心移动区，也是你接下来几节课要反复练习的“家”。

> *Kate 摸了摸 J 键上的小凸起，问道：“所以这不是乱安排的，是手指放上去刚好能够到？”*
> *“没错，最舒服的姿势，就是最高效的姿势。”*

**小结**：你用 `hjkl` 移动光标，不是因为这样最科学，是因为 1976 年那台机器的键帽上就是这么印的。四十年后，这个“偶然”成了所有 Vim 用户的肌肉记忆。

---

#### 1.4 什么是终端？

Vim 运行在 **终端** 里。

终端是一个“能打字跟电脑说话的黑框框”。不同系统的叫法不同：

- Windows：命令提示符 或 PowerShell
- Mac：终端
- Linux：终端

> 如果你没用过终端，没关系。你现在只需要知道：Vim 住在里面。打开终端，输入 `vim`，就能启动。

**小结**：终端是 Vim 的“家”。先打开终端，再启动 Vim。

---

#### 1.5 安装 Vim

**不知道你的电脑是什么系统？**

- 左下角有“开始”菜单 → Windows
- 左上角有苹果图标 → Mac
- 不知道 → 大概率是 Windows

根据你的系统，选一个方法。

---

##### 1.5.1 Windows 用户

Windows 本身没有 Vim。需要先安装 **WSL**（Windows 上的 Linux 子系统）。

> 别被名字吓到。你可以把 WSL 理解成“Windows 电脑里的另一台小电脑”，专门用来跑 Linux 程序。装一次就行。
>
> *Kate 举手了：“等等，我是不是一定要用命令行来装？我看到‘以管理员身份运行’就害怕。”*
> *“别怕，Kate。你也可以去 GitHub 下载安装包，双击运行，像装普通软件一样。”*

**方法一：命令行安装（推荐）**  

1. 打开“开始”菜单，搜 `PowerShell`
2. **右键点击“PowerShell”，选择“以管理员身份运行”**（这一步很重要）
3. 在黑框框里输入下面这行命令，按回车：

   ```bash
   wsl --install
   ```

4. 等几分钟，**重启电脑**。系统会自动帮你装好一个 Ubuntu。
5. 重启后，打开“开始”菜单，搜 `Ubuntu` 并打开
6. 第一次打开要等一会儿，然后让你输入**用户名和密码**。随便写（比如 `vimer`），别忘
7. 在 Ubuntu 里输入下面这行命令，按回车：

   ```bash
   sudo apt update && sudo apt install vim -y
   ```

**方法二：手动安装（不喜欢命令行就用这个）**  

1. 访问 [https://github.com/microsoft/WSL/releases](https://github.com/microsoft/WSL/releases)，下载最新的 `wsl.2.x.x.x64.msi` 安装包。
2. 双击运行，一路 Next 安装完成，**重启电脑**。
3. 重启后，打开开始菜单里的“Ubuntu”，创建用户名和密码。
4. 进去后输入 `sudo apt update && sudo apt install vim -y` 即可。

> **⚠️ 注意：** 如果你想把 Ubuntu 安装到 D 盘而不是 C 盘，可以使用以下命令：
>
> ```bash
> wsl --install -d Ubuntu --install-location D:\WSL
> ```
>
> 这样整个 Ubuntu 系统就会直接装在 D 盘，省去了后面搬家的麻烦。

---

##### 1.5.2 Mac 用户

Mac 自带老版的 `vi`，需要装新版的 Vim。

1. 打开“启动台”→“其他”→**“终端”**
2. 先装 Homebrew（Mac 的软件管家）。在终端里粘贴下面这行命令，按回车：

   ```bash
   /bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
   ```

   等几分钟，中间可能让你按回车确认
3. 装完后，在终端里输入：

   ```bash
   brew install vim
   ```

---

##### 1.5.3 Linux 用户

打开终端（快捷键通常是 `Ctrl+Alt+T`），输入：

```bash
sudo apt install vim -y
```

如果提示 `command not found`，把 `apt` 换成 `yum` 或 `pacman`。

**小结**：按自己系统的步骤来，一步一步敲命令。装不上就去搜报错信息。

---

#### 1.6 验证安装

安装完成后，在终端里输入：

```bash
vim --version
```

按回车。

如果屏幕上出现一大堆以 `VIM` 开头的信息，中间有 `Huge version` 之类的字眼——**Vim 安装成功**。

如果提示 `command not found`，说明没装上。检查哪一步命令打错了，或者关掉终端重新打开再试一次。

**小结**：`vim --version` 是验证命令。看到 `VIM` 就对了。

#### 1.7 第一次启动

在终端里输入 `vim`，按回车。

画面变了。屏幕上有版本号、帮助提示，底下有一行状态条。

**你现在在 Vim 的“普通模式”下。**

试试按一下字母 `i`，你会发现——你能打字了。按 `i` 进入了“插入模式”。

现在不需要搞懂模式是什么。你只需要知道：**你怎么退出去？**

> *Kate 按了 i，看到屏幕底部出现了 `-- INSERT --`，松了口气：“还好还好，这步我熟。但是……我怎么退出去？”*
> *“好问题。这是今天最重要的知识点。”*

**活着退出去的方法（这是 Vim 最重要的操作）**  

1. 按 **`ESC`** 键（键盘左上角）
2. 输入冒号 **`:`**（左下角会出现冒号）
3. 输入 **`q!`**（左下角变成 `:q!`）
4. 按 **回车**

屏幕闪了一下，你回到了终端。

> `q!` 的含义：
>
> - `:` 进入命令行模式
> - `q` 是 quit（退出）
> - `!` 是强制。你没保存任何内容，不加 `!` Vim 会拦着你，加了这个就是告诉它：我知道没保存，退！

**小结**：`ESC` → `:` → `q!` → 回车。这四个动作是你的“救命稻草”。记不住这四步，别的都不需要学。

#### 1.9 本课作业

1. 搜一下：Bram Moolenaar 除了写 Vim，还做了什么让很多人佩服的事？
2. 把 Vim 启动界面截图存下来。这是你和 Vim 的“第一次见面”。

**守夜者宣言**：第一课的使命不是让你“学会”，而是让你“不怕”。你已经知道了 Vim 的故事，知道了为什么用 `hjkl`，把它请进了门，还活着退了出来。这就够了。

下一课：打开文件、保存、退出——也就是“活着进去，活着出来”。

### 第二课：打开、编辑与保存 —— 活着进去，活着出来

上一课你学会了启动 Vim 并活着退出来。这一课我们往前一步：**打开一个文件，写点东西，保存，然后退出。**

这套动作，你以后每天会重复几十遍。

---

#### 2.1 打开文件

在终端里，输入 `vim` 后面跟上文件名：

```bash
vim 笔记.md
```

按回车。

如果这个文件**不存在**，Vim 会帮你创建一个空的“缓冲区”——你可以理解成“一张白纸，还没保存到硬盘上”。等你保存的时候，它才会真正变成硬盘上的文件。

如果这个文件**已经存在**，Vim 会打开它，显示里面的内容。

> 文件名可以带路径。比如 `vim ~/Documents/笔记.md`，会在你的“文档”文件夹里创建或打开这个文件。

**小结**：`vim 文件名` = 打开或新建一个文件。

---

#### 2.2 写点东西

现在你面对的是一个空白的屏幕（或者已有内容）。但你打不了字。

还记得上一课吗？启动 Vim 后，默认在“普通模式”下。普通模式下，键盘上的字母不是用来打字的，是用来下命令的。

想打字？按 `i`。

`i` 是 **insert**（插入）的缩写。按一下，左下角会出现 `-- INSERT --` 字样。现在你可以打字了。

试试敲一行：

```vim
Hello, Vim!
```

> *Kate 按了 `i`，看到 `-- INSERT --` 出现。她敲了 `Hello, Vim!`，然后说：“终于打上字了。我上次打开 Vim，按了半天键盘什么都没出现，我以为它坏了——原来是我没按 `i`。”*

很好，你已经学会了 Vim 里最重要的技能之一：进入插入模式，然后写字。

> `i` 表示在光标所在位置开始插入。还有几个变体：
>
> - `I`：跳到行首开始插入
> - `a`：光标后一位开始插入
> - `A`：跳到行尾开始插入
> - `o`：在下一行新建一行开始插入
> - `O`：在上一行新建一行开始插入
>
> 你现在只需要知道 `i` 就够了。其他的，用到的时候再回来翻。

**小结**：按 `i` 进入插入模式，然后像用记事本一样打字。

---

#### 2.3 保存文件

打完字了，怎么保存？

**先回到普通模式**。按 `ESC` 键（记住了吗？这是你的万能钥匙）。

然后输入 `:w`，按回车。

`:w` 是 **write**（写入）的缩写。把当前内容写入硬盘上的文件。

> 为什么用这些奇怪的字母？  
> 因为 Vi 诞生于 1976 年，那个时代还没有图形界面，没有 `Ctrl+S` 这种快捷键。  
> 所有的操作都是通过在普通模式下输入英文缩写来完成的。  
> `w` 是 write，`q` 是 quit，`i` 是 insert。它们不是随意挑的字母，是英文单词的首字母。你不需要背它们——你只需要知道它们代表什么英文单词。

左下角会显示 `"笔记.md" [新] 已写入` 之类的信息。文件保存成功了。

> *Kate 敲完了她的第一行笔记，按 `ESC`，输入 `:w`，回车。看到左下角的“已写入”提示，她说：“这就保存了？我在 VS Code 里保存是按 Ctrl+S，肌肉记忆太深了。在这里要按 ESC 然后 :w——但效果一样。”*

你可以继续写，随时按 `ESC` + `:w` 保存。养成习惯：写一会儿就保存，别等到最后。

**小结**：`ESC` → `:w` → 回车 = 保存。

---

#### 2.4 保存并退出

写完了，想关掉文件并退出 Vim。

在普通模式下输入 `:wq`，按回车。

`:wq` 是 **write + quit**（写入并退出）。

先保存，再退出。跟先 `:w` 再 `:q` 是一个效果，只是合并成了一步。

**小结**：`ESC` → `:wq` → 回车 = 保存并退出。

---

#### 2.5 不保存退出

如果写了一堆乱码，或者改错了，不想保存，直接走人。

输入 `:q!`，按回车。（这就是上一课学的“活着退出去”）

`:q!` = **quit + 强制**。放弃所有修改，直接退出。不加 `!` 的话，Vim 会警告你“有修改未保存，不让你退”。加了 `!` 就是“别管了，我不要了！”

> *Kate 故意写了一段乱码，然后按 `ESC`，输入 `:q!`，回车。Vim 直接关了，没有任何提示。她重新打开文件——乱码没被保存，文件还是原来的样子。她说：“所以 `:q!` 是‘我刚才写的东西全不要了’。这个命令在试错的时候特别好用——试验了一个新写法，不好，直接 `:q!` 走人。”*

**小结**：`ESC` → `:q!` → 回车 = 不保存直接退出。

---

#### 2.6 完整流程演示

把刚才学的串起来：

```bash
vim 守夜者笔记.md    # 打开文件
```

按 `i`进入插入模式

```vim
今天学了 Vim 的基本操作。
感觉还行，不算太难。
```

按 `ESC`回到普通模式

`:w` 回车保存

按 `i`继续插入

```vim
明天学移动光标。
```

按 `ESC`回到普通模式

`:wq` 回车保存并退出

**完事。你已经在 Vim 里写了一份完整的笔记，保存，退出来了。**

> *Kate 照着这段流程完整走了一遍，打开文件、写字、保存、继续写、保存退出。她说：“我刚刚在 Vim 里写完了人生第一份完整的笔记。不是练习，是真的笔记——写了字、存了盘、退了出来。我现在不怕 Vim 了。”*

---

#### 2.7 命令速查

| 命令 | 效果 |
| :--- | :--- |
| `vim 文件名` | 打开/新建文件 |
| `i` | 进入插入模式（开始打字） |
| `ESC` | 回到普通模式 |
| `:w` | 保存 |
| `:wq` | 保存并退出 |
| `:q!` | 不保存强制退出 |
| `:q` | 退出（没有修改时可用） |

---

#### 2.8 小结

```text
vim 文件名 → i（打字）→ ESC（退出打字）→ :w（保存）→ i（继续打字）→ ESC → :wq（保存并退出）
```

如果你改错了不想保留：把最后一步换成 `:q!`。

**这就是 Vim 最核心的工作流。** 学会了这套动作，你就能在 Vim 里写任何东西。剩下的所有命令，都是让这套动作“更快更爽”的附加招式。

#### 2.9 本课作业

1. 用 Vim 新建一个文件，叫 `vim-测试.md`
2. 在里面写一句话（比如：“今天是 2026 年 6 月 26 日，我开始学 Vim。”）
3. 保存并退出（`:wq`）
4. 重新用 Vim 打开它（`vim vim-测试.md`），确认内容还在
5. 追加一行，然后不保存退出（`:q!`）
6. 重新打开文件，确认第二行**没有**被保存

**守夜者宣言**：你刚刚完成了一个完整的 Vim 工作流——从打开文件、写字、保存、到退出。你已经在 Vim 里完成了一份真正的笔记。这套动作你以后每天会重复几十遍，今天练熟它。下一课：移动光标。

### 第三课：移动光标 —— 让手指告别方向键

上一课你学会了在 Vim 里打开文件、打字、保存退出。你用的是 `i` 进入插入模式，在插入模式里写字——写的时候，你肯定用方向键移动过光标。

这一课，我们把方向键戒了。

**原因很简单：方向键在键盘右边，每次按它，右手都得离开主键盘区。一天下来，你的右手在方向键和主键盘区之间来回跑几十公里。**

Vim 的方案：**让手指不离开主键盘区就能移动光标。**

---

#### 3.1 核心四键

| 键  | 方向 |
| :-- | :--- |
| `h` | 左   |
| `j` | 下   |
| `k` | 上   |
| `l` | 右   |

把它们刻进脑子里。这是 Vim 的“方向键”。

**实际手感**：

把右手食指放在 `J` 键上。`J` 键上有一个小凸起，你的食指应该能摸到它——那是定位点，帮你找到“家”。

- 食指不动 → 在 `J` 上 → 按 `j` → 光标**向下**
- 食指向上移一格 → 在 `K` 上 → 按 `k` → 光标**向上**
- 食指不动、中指向左移一格 → 在 `H` 上 → 按 `h` → 光标**向左**
- 食指不动、无名指向右移一格 → 在 `L` 上 → 按 `l` → 光标**向右**

> 第一次用会觉得很别扭。这很正常。所有 Vim 新手第一周都在跟这四个键打架。

---

> *Kate 把手放在 `hjkl` 上试了试，说：“我按了十年的方向键，现在突然告诉我这四个字母才是方向键。我的右手正在抗议。”*
>
> “抗议一周就好了。一周之后，你的右手不会再想离开主键盘区。”

**试试看**：

1. 打开 Vim：`vim 测试.md`
2. 按 `i` 进入插入模式
3. 随便敲几行字，比如：

    ```vim
    第一行
    第二行
    第三行
    第四行
    ```

4. 按 `ESC` 回到普通模式
5. 用 `h` `j` `k` `l` 在行间上下移动、在行内左右移动

**小结**：`hjkl` 是 Vim 的方向键。初期可能不习惯，练一练就好。

---

#### 3.2 进阶移动：在普通模式里“跳”

`hjkl` 适合在附近慢慢移动。但如果你要从文件第一行跳到最后一行，一直按 `j` 太慢了。Vim 提供了更快的方式：

**跳到行首或行尾**  

| 命令 | 效果 |
| :--- | :--- |
| `0`（数字零） | 跳到当前行的行首 |
| `^` | 跳到当前行的第一个非空字符（行首有空格就跳过空格） |
| `$` | 跳到当前行的行尾 |

试试：`$` 在键盘上需要按 `Shift+4`。

**跳到文件开头或结尾**  

| 命令 | 效果 |
| :--- | :--- |
| `gg` | 跳到文件第一行 |
| `G` | 跳到文件最后一行 |

试试：连按两次 `g`（`gg`），光标飞到文件顶部。按一次 `G`，光标飞到文件底部。

**这比一直按 `j` 快多了。**

> *Kate 打开了她那篇 200 行的笔记，按了 `gg`，光标瞬间跳到了第一行。又按了 `G`，光标飞到了最后一行。她说：“我每次想回第一行的时候都一直按着 `j` 不放——像个傻子。”*

**翻页**  

| 命令 | 效果 |
| :--- | :--- |
| `Ctrl + f` | 往下翻一页（forward） |
| `Ctrl + b` | 往上翻一页（backward） |

试试：按住 `Ctrl` 再按 `f`，屏幕内容往下翻一页。

> `f` 是 forward（向前），`b` 是 backward（向后）。**注意：`Ctrl+f` 是翻页，不是搜索。**（搜索是下一课的内容，别急。）

**小结**：`gg` 飞到文件顶部，`G` 飞到文件底部，`0` 到行首，`$` 到行尾。

---

#### 3.3 按词移动：比“一个一个字符”快

`h` `l` 一个一个字符移动还是太慢。Vim 提供了按“词”移动：

| 命令 | 效果 |
| :--- | :--- |
| `w` | 跳到下一个单词的开头 |
| `b` | 跳到上一个单词的开头 |
| `e` | 跳到下一个单词的末尾 |

试试：

```text
hello world from vim
```

光标在行首：

- 按 `w` → 跳到 `world`
- 再按 `w` → 跳到 `from`
- 再按 `w` → 跳到 `vim`

按 `b` 就倒着走。

按 `e` 跳到单词末尾。如果你要从“hello”的 `h` 跳到 `o`，按一次 `e` 就到了。

**小结**：`w` 跳下一个词，`b` 跳上一个词，`e` 跳到词尾。

#### 3.4 课堂练习

### 第四课：插入模式 —— 不只是按个 `i` 那么简单

上一课你学会了在普通模式里移动光标。这一课我们进入插入模式——但这次不只是按 `i` 那么简单。

你可能已经发现了：**普通模式是“指挥模式”，插入模式是“写字模式”。**

普通模式下，键盘是遥控器——按 `gg` 飞到文件头，按 `G` 飞到文件尾，按 `dd` 删一整行。插入模式下，键盘是打字机——按什么键就出什么字。

**Vim 的核心理念**：在普通模式下“指挥”，在插入模式下“写字”。写完立刻按 `ESC` 回去继续指挥。

**新手最容易犯的错误**：一直待在插入模式里，用方向键移动光标，用退格键删改。如果这样用，Vim 跟记事本没区别，你白白放弃了它最大的优势。

> *Kate 在上一课练习 `hjkl` 的时候，好几次忘了自己在什么模式。她说：“我在插入模式里按了 `j`，结果屏幕上出现了字母 j，不是光标向下。然后我又按方向键，屏幕上出现了一堆奇怪的字符——我卡在插入模式里出不来了。”*
>
> *“这就是今天要解决的问题。在插入模式下按方向键，就像在水下呼吸——你使错劲了。今天学完，你不会再卡在插入模式里。”*

所以关键不是“怎么进入插入模式”，而是 **“怎么最快最准地进入插入模式，把字写在正确的位置”**。

---

#### 4.1 进入插入模式的六种方式

| 命令 | 效果 | 使用场景 |
| :--- | :--- | :--- |
| `i` | 在光标**前**插入 | 最常用。光标在“界”上，想在前面加个“世” → 按 `i`，输入“世” |
| `a` | 在光标**后**插入 | 光标在“世”上，想在后面加个“界” → 按 `a`，输入“界” |
| `I` | 在行**首**插入 | 想在一行开头加东西，不用先按 `0` 再按 `i`，直接 `I` 一步到位 |
| `A` | 在行**尾**插入 | 想在一行末尾加东西，不用按 `$` 再按 `a`，直接 `A` 一步到位 |
| `o` | 在**下一行**新建一行插入 | 想在当前行下面加一行，不用按 `A` 回车再打字，直接 `o` |
| `O` | 在**上一行**新建一行插入 | 想在当前行上面加一行，直接 `O` |

假设光标停在第一行的“界”上：

```vim
世|界
```

按什么键，光标会出现在哪里？

| 按 | 结果 | 说明 |
| :--- | :--- | :--- |
| `i` | 世 \| 界 | 光标停在“世”和“界”之间，直接在原地写 |
| `a` | 世界 \| | 光标跑到“界”的后面，接着写 |
| `I` | \| 世界 | 光标跳到行首，在“世界”前面写 |
| `A` | 世界 \| | 光标跳到行尾，在“世界”后面接着写 |
| `o` | 世界（新建一行）\| | 在下面新建一行，光标在新行开头 |
| `O` | \|（新建一行）世界 | 在上面新建一行，光标在新行开头 |

你不需要一下子记住全部。**先记住 `i`，然后逐步加上 `A` 和 `o`**，这三个最常用：

- `i`：光标前插入（基础）
- `A`：行尾插入（省去按 `$` 再按 `a`）
- `o`：下方新开一行（省去按 `A` 回车）

> *Kate 看着表格，小声嘀咕：“这么多？”*
>
> “不多。你这辈子 80% 的时间只用这三个：`i`、`A`、`o`。剩下三个是偶尔救急用的。”

**小结**：`i` 光标前，`a` 光标后，`I` 行首，`A` 行尾，`o` 下一行，`O` 上一行。

---

#### 4.2 从插入模式退出来

按 `ESC`。

这是 Vim 里最常用的键。打完字，第一件事就是按 `ESC` 回到普通模式。

**错误示范**：打完字不按 `ESC`，直接按方向键移动光标。

结果：插入模式里插入了各种你根本不想打的字符。

**正确做法**：打完字 → 按 `ESC` → 再移动光标。

> *Kate 说：“每次打字都要按 `ESC`，好烦。”*
>
> “烦一周。一周之后你就感觉不到 `ESC` 了，它变成了你的肌肉本能。到时候你在 VS Code 里打完字，也会下意识去按一下左上角——然后发现 VS Code 不理你。”

**小结**：`ESC` 回到普通模式。打完字先按 `ESC`，再做其他操作。

---

#### 4.3 日常最常用的三种进入方式

学会六种方式是基础，但真正提高效率的，是知道**什么时候用哪一种**。

**`A` —— 在行尾接着写**

你正在写一行字，写完了发现少了个句号。

如果你的光标在行中间某处：

- 不用 `A`：按 `$` 跳到行尾，再按 `a` 进入插入模式，再输入句号 → 三步
- 用 `A`：直接按 `A`，光标跳到行尾并进入插入模式，输入句号 → 一步

省两步。但更关键的是：**你不需要先跳到行尾。直接按 `A`，Vim 替你跳了。**

> *Kate 说：“我写代码的时候，经常写完一行发现忘了加分号。以前在 VS Code 里是按 End 键跳到行尾再加。现在直接按 `A`，我的手指不用去找 End 键了。”*

**`o` —— 在下面另起一行**

你正在写笔记，想换一行继续写。

- 不用 `o`：按 `A` 跳到行尾，按回车，打字 → 三步
- 用 `o`：直接按 `o`，在下一行新建一行并进入插入模式 → 一步

**`O` —— 在上面另起一行**

你想在当前行**上面**插入一行——比如你想在已有的两段文字之间补一段。

- 不用 `O`：先按 `O`……等一下，没有不用 `O` 的替代方案。如果不学 `O`，你只能先跳到上一行的行尾，按回车，再打字——又慢又笨。
- 用 `O`：直接按 `O`，在上一行新建一行并进入插入模式 → 一步

每天几十次“省两步”，一年下来省多少？**几千次按键。**

> *Kate 试了一下 `A` 和 `o`，说：“这两个好用。我决定原谅 `hjkl` 了。”*

---

#### 4.4 练习：建立模式切换的肌肉记忆

**核心原则**：普通模式是“家”，插入模式只是“出门散步”。

打字的时候想着：

1. 按 `i` 或 `A` 或 `o` → 出门散步
2. 打几个字 → 散步
3. 按 `ESC` → 回家
4. 用 `h` `j` `k` `l` 或 `w` `b` → 在家里走到下一个位置
5. 按 `i` 或 `A` 或 `o` → 再次出门

**你不是“在插入模式里写很久，偶尔出来移动一下”。而是“在普通模式里移动，偶尔进入插入模式写几个字”。**

练习的时候，刻意制造这种切换：

1. 按 `i` → 打一个词 → 按 `ESC`
2. 按 `h` `j` `k` `l` 移动几格 → 按 `i` → 打一个词 → 按 `ESC`
3. 按 `A` → 在行尾打一个词 → 按 `ESC`
4. 按 `o` → 在下一行打一个词 → 按 `ESC`

一开始会觉得切换很烦。一周后，你的手指会自动去找 `ESC`。到那时候，你在 VS Code 里打完字也会下意识去摸左上角——那是你的 Vim 肌肉记忆在跟你开玩笑。

**小结**：Vim 的效率核心是“模式切换”——写完字立刻退出来，用普通模式指挥，再进去写。

---

#### 4.5 本课小结

| 命令 | 效果 |
| :--- | :--- |
| `i` | 光标前插入 |
| `a` | 光标后插入 |
| `I` | 行首插入 |
| `A` | 行尾插入（⭐ 强烈推荐） |
| `o` | 下方新建一行插入（⭐ 强烈推荐） |
| `O` | 上方新建一行插入 |
| `ESC` | 回到普通模式（救命键） |

**习惯养成**：打完字按 `ESC`，再移动光标。**在插入模式里，手指只打字。移动光标的事情，交给普通模式。** 第三课说“方向键在 Vim 的世界里不存在了”，这一课加一句：“写完字就回家。”

---

#### 4.6 本课作业

1. 打开 Vim，新建一个文件
2. 打一行字，比如：

    ```vim
    Vim 有六种进入插入模式的方式
    ```

3. 分别用 `i`、`a`、`I`、`A`、`o`、`O` 在这个文件里练习：
   - 在“Vim”前面加个“好”字（用 `i`）
   - 在“方式”后面加个“。”（用 `A`）
   - 在这行下面新建一行，写“今天学到了”（用 `o`）
   - 在这行上面新建一行，写“笔记：”（用 `O`）
4. 每做完一步，按 `ESC` 退出，再想一下：刚才那一步有没有更快的进入方式？
5. 保存退出

**守夜者宣言**：普通模式是家，插入模式是出门散步。写完字就回家（按 `ESC`），在家里指挥（移动/删除/复制），再出门散步（按 `i`/`A`/`o`）。这一课的练习，就是让你习惯这个节奏。

下一课：`.` 命令 —— Vim 里的“懒人键”。

### 第五课：`.` 命令 —— 做一次，重复无数次

前四课你学会了移动光标（`hjkl`、`gg`、`G`、`w`、`b`）、进入插入模式（`i`、`A`、`o`）、保存退出（`:w`、`:wq`）。你现在已经能“用”Vim 了——打开文件、写字、保存、关掉。

但“用”和“快”之间，隔着一条河。

这一课，我们过河。工具就是 `.` 命令。

> Vim 的设计哲学里有一句话：“你做一遍，我帮你重复。” `.` 命令就是这句话的化身。它不是快捷键——它是 Vim 对你说的“我懂了，接下来交给我”。所有高手的肌肉记忆，都建立在这一句话上。

---

#### 5.1 什么是 `.` 命令？

`.` 是 Vim 里的一个命令：**重复上一次修改。**

“修改”的定义很宽：删除、插入、替换、缩进……几乎所有改变文本内容的操作，都算“修改”。

**简单说**：你做了一个改动，按 `.`，Vim 会原封不动地再做一次。

你看完这一整句，心里可能有句话：“就这？一个重复键？”

对，就一个键。但这一课的篇幅都在告诉你：这一个键，是 Vim 最高频、最核心的命令。没有之一。

---

#### 5.2 第一次体验：震惊

打开 Vim，敲几行字：

```vim
Line 1
Line 2
Line 3
Line 4
Line 5
```

按 `ESC` 确保在普通模式。

1. 按 `dd` 删掉第 1 行（`dd` 是“删除整行”）
2. 按 `.` —— **第 2 行没了**
3. 再按 `.` —— **第 3 行没了**
4. 再按 `.` —— **第 4 行没了**

看着屏幕上的行一行行消失，你可能会愣住。这就是 `.` 命令给你的第一印象：**它记住了你刚做了什么，然后重复执行。**

> *Kate 试了一下，盯着屏幕说：“我按了三次点，它删了三行。而我什么都没数。”*
>
> “没错。你不需要数‘我要删 5 行’，你只需要说‘删一行’，然后按 5 次 `.`。脑子不用算数，手指不用重新敲 `dd`。”

---

#### 5.3 `.` 命令能重复什么？

`.` 命令会记录你最近的一次**普通模式下的编辑操作**。它**不记录**移动光标、搜索等非编辑操作。

`.` 命令**能**重复的典型操作：

- 删除（`dd`、`x`、`dw`）
- 修改（`c`、`s`、`r`）
- 插入（`i` + 文字 + `ESC`）
- 粘贴（`p`）
- 缩进（`>>`、`<<`）

`.` 命令**不能**重复的操作：

- 移动光标（`h`、`j`、`k`、`l`、`w`、`b`、`gg`、`G`）
- 搜索（`/`、`?`）
- 撤销（`u`）
- 保存（`:w`）
- 退出（`:q`）

---

#### 5.4 “点公式”—— Vim 效率的核心公式

《Vim 实用技巧》这本书里，提出了一个概念叫 **“点公式”**：

> **用一次按键移动光标，用另一次按键执行修改。**
> **移动 + 执行，再移动 + 再执行。**

看两个例子你就懂了：

**例 1：给多行代码加分号**  

你有一组变量声明，每行末尾少了分号。你想给它们加上。

```javascript
var foo = 1
var bar = 2
var baz = 3
```

第一次：

- 按 `A` → 跳到行尾，进入插入模式
- 输入 `;` → 加分号
- 按 `ESC` → 回到普通模式

第二次（把光标移到下一行，然后重复修改）：

- 按 `j` → 光标移到下一行
- 按 `.` → 重复刚才的“A;ESC”组合，**即：跳到行尾 → 加分号 → 回到普通模式**

你只需要：

1. 在第一行做一次完整的修改（A → ; → ESC）
2. 然后：`j` → `.` → `j` → `.` → `j` → `.`

**三行代码，三次移动，三次点，全部搞定。**

**例 2：在每行开头加 `#`**

```vim
第一行
第二行
第三行
```

第一次：

- 按 `I` → 跳到行首，进入插入模式
- 输入 `#` → 加注释符
- 按 `ESC` → 回到普通模式

然后：

- `j` → `.` → `j` → `.`

**关键**：`.` 记住了你做的**整个**修改，从进入插入模式到退出。`A`、`I`、`o`、`O` 这些命令，在 `.` 面前等价——它们都是“进入插入模式 → 打字 → 退出来”这一整段操作。

> *Kate 试了加分号的例子，说：“我平时会一行一行地敲分号，或者用替换命令 `:%s/$/;/`。你告诉我用 `j` 加 `.`？”*
>
> “两种都对。`.命令` 比替换命令更可控——你每按一次 `.`，都看得到效果。万一哪行不该加，你也不会改错。”

---

> *学 `.` 命令之前，你看到 100 行没有分号的代码，心里想的是“我要一行一行敲，敲到什么时候”。学 `.` 命令之后，你看到 100 行没有分号的代码，心里想的是“做一次，然后按 99 次 `.`”。工作量没变——但你的心态变了。从“我做 100 次”变成了“我做 1 次，Vim 帮我做 99 次”。*

---

#### 5.5 互动练习：给多行代码加分号

打开 Vim，输入：

```javascript
var a = 1
var b = 2
var c = 3
var d = 4
```

`ESC` 确保在普通模式。

第一行：

- 按 `A` → 跳到行尾，进入插入模式
- 输入 `;` → 加分号
- 按 `ESC` → 回到普通模式

然后：

- 按 `j` → 移到第二行
- 按 `.` → 自动给第二行加分号
- 按 `j` → 移到第三行
- 按 `.` → 自动给第三行加分号
- 按 `j` → 移到第四行
- 按 `.` → 自动给第四行加分号

**你按了多少次键？**

- 第一次修改：`A`、`;`、`ESC`（3 次）
- 后面三行：`j`、`.`、`j`、`.`、`j`、`.`（6 次）
- **一共 9 次**

如果不用 `.` 命令：每行 `A`、`;`、`ESC`、`j`（4 次 × 4 行 = 16 次）。

**省了 7 次按键。** 而且随着行数增加，省下的按键越来越多。100 行的话，`.命令` 方案按约 200 次，手动方案按约 400 次。**省一半。**

---

#### 5.6 避坑提醒

`.` 只记录**最后一次修改**。如果你做了修改 A，然后按了移动命令 `j`，`.` 记录的还是修改 A。**移动命令不会覆盖 `.` 的记忆。**

但如果你做了修改 A，然后做了修改 B（比如按 `dd` 删了一行），`.` 就变成重复修改 B 了。

> 问：那如果我按了 `u` 撤销，`.` 会重复什么？
> 答：`.` 会重复你按 `u` 之前的那次修改。`u` 是撤销命令，不是“修改”命令，不会覆盖 `.` 的记忆。

---

#### 5.7 本课小结

| 命令 | 效果 |
| :--- | :--- |
| `.` | 重复上一次修改 |

**点公式**：移动 → `.` → 移动 → `.` → 移动 → `.` ......

> *Kate 说：“学会 `.` 之后，再回去看前四课的练习——`dd` 删除、`I` 加注释、`A` 加分号——所有这些都可以用 `.` 再来一遍。以前的练习是一遍一遍做，现在的练习是一遍加九十九遍 `.`。”*

**一句话记住这节课**：`.` 命令的核心思想是——**“先做一次，然后重复做”**。不要想着“我要做 10 次”，想着“我做 1 次，再按 9 次 `.`”。Vim 会替你数，你只需要按。

---

#### 5.8 本课作业

1. 在 Vim 里随便打 10 行文字
2. 用 `dd` 删掉第一行，然后用 `.` 删掉剩下的 9 行（不要数，按到没有行为止）
3. 重新输入 10 行，每行前面加一个 `-`（用 `I` 加 `-`，然后用 `j` + `.` 完成剩下的）
4. 保存退出

**守夜者宣言**：`dd` 删一行不难。但如果要删 10 行、20 行、50 行呢？`.` 命令让你不用数“删几行”，只做“删一行”，然后重复到完事。这一课的练习，就是让你感受这种“不数数”的快乐。

### 第六课：删除、撤销与恢复 —— 做错了也不怕

上一课你学会了 `.` 命令——做一次修改，然后重复无数次。这一课我们回到“修改”本身：**怎么删、怎么改、怎么反悔。**

如果说普通模式下移动光标是“走路”，那么**删除、撤销、改错**就是“编辑三件套”——你在 Vim 里 80% 的编辑操作，都在这三种命令的范围内。这一课讲删除和撤销，后面几课会陆续解锁更高级的编辑命令。

---

#### 6.1 删除基础命令

| 命令 | 效果 | 对应“动作”描述 |
| :--- | :--- | :--- |
| `x` | 删除光标下的一个字符 | “删掉光标这个位置上的一个字符” |
| `X` | 删除光标前的一个字符 | “删掉光标前面的那个字符” |
| `dd` | 删除整行 | “删掉这一整行” |
| `D` | 删除从光标到行尾 | “删掉从这里到行尾” |

试试：

```vim
Hello World
```

光标停在 `W` 上：

- 按 `x` → 删掉 `W`，变成 `Hello orld`
- 按 `X` → 删掉 `o`（光标前的字符），变成 `Hell orld`（你试一下就明白）
- 按 `dd` → 整行消失
- 按 `D` → 从光标到行尾全部删除（光标在 `H` 上，按 `D` 整行清空，留下一个空行）

---

> *Kate 试了一下 `dd`，说：“之前删整行我要按着退格键好久。现在一下没了，感觉有点不真实。”*
>
> “这就是 Vim 的节奏。按一下，整个世界清净了。如果你删错了——下一节教你怎么反悔。”

---

#### 6.2 删除 + 移动 = 组合技

这是 Vim 真正的威力所在。

**公式：`d` + 移动命令 = 删除从当前位置到目标位置之间的内容。**  

这个公式适用于 Vim 中所有带“动作”的命令。但这一课我们先只讲 `d` 的用法。

| 组合 | 效果 | 描述 |
| :--- | :--- | :--- |
| `dw` | 删除到下一个单词的开头 | `d` + `w`（移动到下一个单词） |
| `db` | 删除到上一个单词的开头 | `d` + `b`（移动到上一个单词） |
| `d$` | 删除到行尾 | `d` + `$`（移动到行尾） |
| `d0` | 删除到行首 | `d` + `0`（移动到行首） |
| `dG` | 删除到文件末尾 | `d` + `G`（移动到文件末尾） |
| `dgg` | 删除到文件开头 | `d` + `gg`（移动到文件开头） |

试试这一行，光标停在开头（`H` 上）：

```vim
Hello world from Vim
```

- 按 `dw` → 删掉 `Hello`（光标停在 `world` 前）
- 再按 `dw` → 删掉 `world`（光标停在 `from` 前）
- 再按 `dw` → 删掉 `from`（光标停在 `Vim` 前）

如果你想把整行删光，`dd` 更快。但 `dw` 适合“只删一部分，不改别的”。

> *Kate 试了 `d$`，说：“我只想删掉这句话最后的几个词，`d$` 一下就删到行尾了。以前我要按着退格键一下一下地删，像在喂一只慢吞吞的兔子。”*
>
> “`d$` 是直接清空整行末尾到行尾的这句话，等你学到查找命令，`d/` 还能删到某个词的位置。”

---

#### 6.3 撤销与重做：后悔药

Vim 里的撤销和重做，比普通编辑器强太多。在普通编辑器（比如记事本或 VS Code）里，撤销是一维的：按 `Ctrl+Z` 一步步倒退，再按 `Ctrl+Y` 一步步前进。Vim 的撤销树是多维的，不过你目前不需要深入了解——你只需要记住两个基本命令：

| 命令 | 效果 |
| :--- | :--- |
| `u` | 撤销上一次修改 |
| `Ctrl + r` | 重做（撤销刚才的撤销） |

试试：删了一行（`dd`），按 `u` —— 它回来了。

再试：删了一行，按 `u` 撤销，按 `Ctrl + r` —— 又没了。

> `u` 是 undo（撤销），`Ctrl+r` 是 redo（重做）。如果你不小心撤销多了，`Ctrl+r` 是反悔药。

---

> *Kate 说：“就这？跟记事本的 `Ctrl+Z` 一样啊。”*
>
> “表面一样。但 Vim 的 `u` 可以撤销很多次，而且它撤销的是‘修改’——不只是‘输入的文字’，还包括删除、替换、缩进……所有编辑操作。另外，记事本撤销多了会丢失历史，Vim 的撤销历史更可靠。”

---

#### 6.4 删除并进入插入模式：`c` 命令

`c` 是 Vim 里的 **change**（修改）命令。它做的事情是：**删除指定的内容，然后自动进入插入模式**，等着你输入新的内容。用 `c` 代替 `d`，相当于把“删除”和“切换到插入模式”合并成一步。

| 组合 | 效果 |
| :--- | :--- |
| `cw` | 删除到下一个单词开头，进入插入模式 |
| `cb` | 删除到上一个单词开头，进入插入模式 |
| `c$` | 删除到行尾，进入插入模式 |
| `c0` | 删除到行首，进入插入模式 |
| `cc` | 删除整行，进入插入模式（相当于 `dd` + `i`） |

**`cw` 是新手最常用的修改命令**。它让你**原地替换一个单词**：

```vim
Hello world
```

光标停在 `world` 的 `w` 上，按 `cw`——`world` 消失了，你进入了插入模式，光标停在 `Hello` 后面。输入 `Vim`，按 `ESC`。

`Hello world` → `Hello Vim`。

**两步：`cw` + 输入新词。** 如果是 `dw` + `i`，需要三步（`dw`、`i`、输入新词）。`cw` 把删除和切换插入模式合并成一步，省了一次按键。

> *Kate 试了 `cw`，说：“我懂了，`cw` 就是‘干掉这个词，然后我来写个新的’。我以前都是删掉再按 `i`，现在是删掉**的同时**按 `i`。”*

---

#### 6.5 替换单个字符：`r` 命令

`r` 是 **replace**（替换）命令。它把光标下的字符替换成你按的下一个字符，然后自动回到普通模式。

试试：

```vim
Hello
```

光标停在第一个 `l` 上，按 `r`，然后按 `X`——`l` 变成 `X`，变成 `HeXlo`。

**一步到位**：按 `r` + 新字符 = 替换。不需要进入插入模式、删掉旧字符、输入新字符、退出插入模式那四步操作。

> *Kate 说：“这个好。有时候我写代码打错一个字母，之前都是按 `i` 进去改，然后再按 `ESC` 出来。现在 `r` 直接一步搞定。”*

---

#### 6.6 本课小结

能删、能改、能反悔——这就是 Vim 最常用的编辑方式。以后你写代码、改配置、修 bug，这套动作会日复一日地出现在你的手指上。

| 命令 | 效果 |
| :--- | :--- |
| `x` | 删除光标下的一个字符 |
| `X` | 删除光标前的一个字符 |
| `dd` | 删除整行 |
| `D` | 删除到行尾 |
| `dw` | 删除到下一个单词开头 |
| `d$` | 删除到行尾 |
| `u` | 撤销 |
| `Ctrl + r` | 重做 |
| `cw` | 删除到下一个单词开头，进入插入模式 |
| `cc` | 删除整行，进入插入模式 |
| `r` | 替换光标下的字符 |

**一句话记住这节课**：`d` 是“干掉”，`u` 是“反悔”，`cw` 是“重写”，`r` 是“纠正”——记住这四条，Vim 编辑最核心的操作你都会了。

1. 打开 Vim，新建一个文件
2. 输入几行文字，然后用 `dd`、`dw`、`d$` 各删除一些内容
3. 用 `u` 撤销每一步，再按 `Ctrl+r` 重做，观察屏幕变化
4. 找一个词，用 `cw` 把它改成另一个词
5. 找一个写错的字母，用 `r` 修正它

**守夜者宣言**：过去三课你学了移动、插入、删除、撤销。你现在已经能——打开文件、在任意位置插入文字、删除任意内容、改错、反悔。这是一套完整的“编辑工作流”。你已经不是在“学 Vim”，你是在“用 Vim”了。

### 第七课：复制、粘贴与缩进 —— 搬砖的艺术

上一课你学会了删除、撤销、修改。这一课我们学“搬东西”——复制、粘贴、缩进。

在普通编辑器里，复制粘贴靠鼠标右键或 `Ctrl+C`/`Ctrl+V`。在 Vim 里，**复制和粘贴是两个独立的命令**，而且 Vim 有自己的“剪贴板”系统——叫 **寄存器**。

但先别急。这一课我们不深入寄存器，只学最常用的操作：**复制一行、粘贴一行、调整缩进。** 这些已经够你应付 80% 的场景了。

---

#### 7.1 复制（Yank）

Vim 里的复制不叫 copy，叫 **yank**。命令是 `y`。

| 命令 | 效果 |
| :--- | :--- |
| `yy` | 复制当前整行 |
| `yw` | 复制到下一个单词的开头 |
| `y$` | 复制到行尾 |
| `y0` | 复制到行首 |
| `yG` | 复制到文件末尾 |
| `ygg` | 复制到文件开头 |

跟 `d` 一样的逻辑：`y` + 移动命令 = 复制从当前位置到目标位置的内容。

试试：

```vim
Hello world from Vim
```

光标停在 `Hello` 的 `H` 上：

- 按 `yw` → 复制 `Hello`
- 按 `y$` → 复制整行（从光标到行尾）
- 按 `yy` → 复制整行（不管光标在行内哪个位置）

---

#### 7.2 粘贴（Put）

复制完了，怎么贴出来？

| 命令 | 效果 |
| :--- | :--- |
| `p` | 在光标**后**粘贴 |
| `P` | 在光标**前**粘贴 |

试试：

```vim
Line 1
Line 2
```

光标停在第 2 行的任意位置：

- 按 `yy` 复制第 2 行
- 按 `k` 移到第 1 行
- 按 `p` → 在第 1 行**后面**粘贴，变成：

```vim
Line 1
Line 2
Line 2
```

如果按 `P`（大写），会在第 1 行**前面**粘贴：

```vim
Line 2
Line 1
Line 2
```

> *Kate 说：“`p` 和 `P` 的区别我记不住。”*
>
> “小写 `p` 是往后放，大写 `P` 是往前放。就像你在排队——小 `p` 是排到后面去，大 `P` 是插队到前面去。”

---

#### 7.3 复制粘贴的练习

1. 打开 Vim，新建一个文件
2. 输入三行：

   ```vim
   第一行
   第二行
   第三行
   ```

3. 把光标移到第二行，按 `yy` 复制
4. 按 `gg` 移到第一行
5. 按 `p` → 第二行被粘贴到第一行后面
6. 按 `u` 撤销
7. 按 `P`（大写）→ 第二行被粘贴到第一行前面

看看区别。

#### 7.4 缩进：让代码整整齐齐

写代码的时候，缩进是家常便饭。Vim 里缩进和反缩进非常简单：

| 命令 | 效果 |
| :--- | :--- |
| `>>` | 当前行向右缩进一次 |
| `<<` | 当前行向左缩进一次 |

试试：

```vim
这行文字
```

光标停在这行，按 `>>`——整行向右移动一个缩进单位（默认是 2 或 4 个空格）。按 `<<`——缩回来。

**多行缩进**：如果你要缩进多行，可以用数字重复：

- `3>>` → 从当前行开始，连续 3 行向右缩进
- `5<<` → 从当前行开始，连续 5 行向左缩进

或者在可视模式里选中多行，按 `>` 或 `<`（和 `>>`/`<<` 效果一样）。可视模式我们在选修课里会讲，这里先用数字重复。

> *Kate 试了一下 `>>`，说：“以前我是按 Tab 键缩进。Vim 里按 `>>` 才缩进，按 Tab 反而会跳到下一格？这得习惯。”*
>
> “Tab 在 Vi 诞生的 1976 年就已经有了自己的含义——在插入模式里输入一个制表符。Bill Joy 不能用 Tab 来做缩进，所以他专门用了 `>>`。习惯之后你会发现 `>>` 更好——因为它永远不会跟你按 `i` 时误按 Tab 混在一起。”

---

#### 7.5 组合拳：复制、粘贴、缩进一块练

场景：你在写一个配置文件，有三行内容，格式不对，想调整。

```vim
第一行内容
第二行内容
第三行内容
```

任务：把“第三行内容”复制一份，放在第二行后面，然后把所有行缩进一次。

步骤：

1. 光标移到第三行 → `yy` 复制
2. `k` 移到第二行 → `p` 粘贴（第二行后面多了一行“第三行内容”）
3. `gg` 移到第一行 → `3>>` 让三行都缩进（因为现在有三行）
4. `:wq` 保存退出

**三件事，六个命令。** 如果让你在鼠标编辑器里做：选中第三行 → Ctrl+C → 鼠标点到第二行后面 → Ctrl+V → 选中三行 → 按 Tab → 保存。哪个快？你自己品。

---

#### 7.6 本课小结

| 命令 | 效果 |
| :--- | :--- |
| `yy` | 复制当前整行 |
| `yw` | 复制到下一个单词开头 |
| `y$` | 复制到行尾 |
| `y0` | 复制到行首 |
| `p` | 在光标后/下粘贴 |
| `P` | 在光标前/上粘贴 |
| `>>` | 向右缩进 |
| `<<` | 向左缩进 |
| `3>>` | 当前行起 3 行向右缩进 |

**一句话记住这节课**：`y` 是复制，`p` 是粘贴，`>` 是缩进。三兄弟各司其职，配合 `.` 命令食用更佳。

#### 7.7 本课作业

1. 打开 Vim，新建一个文件
2. 输入 5 行文字（随便写什么）
3. 复制第 3 行，粘贴到第 1 行后面
4. 复制第 5 行，粘贴到第 2 行后面
5. 用 `>>` 把第 1 行缩进一次，然后用 `.` 命令把剩下 4 行也缩进（或者直接用 `5>>`）
6. 保存退出

**守夜者宣言**：复制粘贴是编辑器里最基础的操作。Vim 让它变得更快——你的右手不需要离开主键盘区去摸鼠标。所有操作都在 `y`、`p`、`>` 这三个键上完成。这一课的练习，就是让这三个键变成你的肌肉记忆。
